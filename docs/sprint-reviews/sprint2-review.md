### Summary:
In this sprint, we laid the foundation for our web application. This was accomplished by creating a Figma design, developing an Entity-Relationship Diagram (EERD), conducting user testing, and setting up the project architecture. We used Vue for the frontend and Spring Boot for the backend, establishing a cohesive framework for the application.

We already have a running demo page, which can be accessed on our domain at https://www.de-kamer.eu. However, there are some areas for improvement, which have been outlined in the list above.

The most significant point for improvement is the lack of a clear vision regarding what we will focus on in the upcoming sprints. Without a defined roadmap, it’s challenging to ensure consistent progress.

In conclusion, we need to refine our planning to better outline our goals and priorities for the future development of the application.s
